# Third-party research and dependencies

RPAK/TUFA/TREE/SDAT research and the initial TREE width/leaf-op interpretation were informed by [EliasFD3S/slrr-reverse](https://github.com/EliasFD3S/slrr-reverse), commit 5c42f3b139aef4c7b9e0b6420c5704e22c0e6cd7. Its license is reproduced below. The TypeScript implementation was written separately and validated against the user's local installation; the typed CONS reader intentionally differs from the reference's heuristic reader.

SCX layout research also consulted nonamesex/io_invo_scx, commit 7bcc34e51a3cb40369cc28db2950ab27f9587078. No source code from that unlicensed checkout is included. Local game assets and original/private sources are not distributed.
