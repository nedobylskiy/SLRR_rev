# Эталон из оригинальной игры: Baiern CoupeSport 2.5

Три снимка экрана получены от пользователя 25 октября 2026 года из той же установленной версии Street Legal Racing Redline, из которой проект читает ресурсы. Числа дословно перенесены в [`reference.json`](reference.json). Изображения сохранены здесь для проверки транскрипции: [характеристики машины](vehicle-specs.png), [график двигателя](engine-graph.png), [результаты на Test Track](test-track-results.png).

Дополнительный [снимок с названием КПП](tourist-transmission-name.png) и исходный `Baiern_Tourist_transmission.java` подтверждают: штатная коробка — **Baiern Tourist 5 speed street automatic transmission**. Поэтому её пять передач с экрана характеристик и из Java являются основой для замера ниже. Другое фото [экрана настройки шести передач](race-man6-tune.png) совпадает с **Baiern Devils RaceMan6 6 speed race manual transmission** в исходном Java (`2.7 / 2.2 / 1.8 / 1.5 / 1.2 / 1.0`, главная пара `2.73`). Эти [данные гоночной коробки](race-man6.json) сохранены отдельно: они не относятся к штатному разгону CoupeSport. Интерфейс показывает `1.799` для третьей передачи при `1.8` в исходнике; причина разницы `0.001` пока не установлена.

Основные ориентиры: 1482 кг, задний привод, 2714 см³ (6 цилиндров, 80×90 мм), холостой ход 1000 об/мин, красная зона 7000 об/мин, 205 Н·м при 4500 об/мин и 194 л.с. при 6250 об/мин. Пять передач и главная пара записаны по игровому экрану. Цель для движения стоковой машины: 0–100 км/ч за 6,109 с, четверть мили за 14,542 с и одна миля за 39,763 с. Показатели времени и скорости подписаны в игре как отдельные «best results» и могут относиться к разным заездам, поэтому расхождение скорости на финише нельзя исправлять ценой неверного времени.

`npm run report:stock-benchmark` собирает штатный `Baiern.rpk:0x06` из локальных игровых файлов и выводит рядом игровые цифры, распознанные Java/CFG-параметры и текущую расчётную кривую. `npm run measure:stock-drive` проводит автоматический прямолинейный разгон на ровной поверхности: после нейтрального старта включает первую передачу, затем замеряет моменты переключения, 0–100 км/ч, четверть и одну милю; `npm run verify:stock-drive` дополнительно проверяет целевой разгон и последовательность передач. Зависимость от локальной установки позволяет также проверить, отличаются ли данные у другого релиза или мода.

После общей настройки, применяемой ко всем машинам, текущий прямолинейный замер даёт около **6,10 с** до 100 км/ч, **14,60 с** на четверть мили и **39,78 с** на одну милю. Коробка переключается 1→2→3→4→5 без скачка сразу к четвёртой. Масса по физическим телам CFG — **1489,6 кг**, что близко к игровым 1482 кг; прежнее добавление условной массы каждой детали завышало её до 1673 кг. Расчёт передачи тяги пока содержит общую эмпирическую поправку, которая убывает с ростом скорости. Это калибровка движения, а не восстановленный native-алгоритм; нужно проверить её на других штатных машинах и модах.

Есть расхождения, которые нельзя устранить одним коэффициентом физики:

- В исходном Java для штатной сборки передачи `3.58 / 2.49 / 1.66 / 1.24 / 1.00`, главная пара `3.03`; экран показывает `3.579 / 2.490 / 1.659 / 1.240 / 1.000` и `3.029`. Следует отдельно выяснить, почему игровое отображение на 0,001 ниже исходных значений.
- Экранные `97,3 л.с./л` не получаются из показанных `194 л.с. / 2,714 л` (это около `71,5 л.с./л`). Аналогично показанные `74,132 кг/Н·м` не равны `1482 / 205` (около `7,23 кг/Н·м`). Эти производные значения сохранены как наблюдения интерфейса, но не являются целями для настройки.
- `194 л.с.` при `6250 об/мин` требуют примерно `221 Н·м` на этих оборотах — больше указанного максимума `205 Н·м`. Возможно, график или подписи используют разные определения мощности/момента либо в игре есть ошибка отображения. До проверки нельзя одновременно требовать от физической кривой точного совпадения с обеими вершинами.

Для сопоставимого автоматического заезда ещё нужны размер/сцепление шин, коэффициенты сопротивления, состояние двигателя, передаточные потери, режим переключения, поверхность и метод старта/финиша оригинальной игры. Они не выводятся из этих трёх экранов.
