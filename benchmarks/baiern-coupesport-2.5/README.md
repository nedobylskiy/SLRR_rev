# Reference from the original game: Baiern CoupeSport 2.5

Three screenshots supplied by the project owner on October 25, 2026, came from the same Street Legal Racing Redline installation used by this project. Their values are transcribed in [`reference.json`](reference.json). The images are retained for verification: [vehicle specifications](vehicle-specs.png), [engine graph](engine-graph.png), and [Test Track results](test-track-results.png).

A [screenshot naming the transmission](tourist-transmission-name.png) and the original `Baiern_Tourist_transmission.java` confirm that the stock unit is the **Baiern Tourist 5 speed street automatic transmission**. Its five ratios, shown on the specification screen and in Java, underpin the measurements below. A separate [six-speed tuning screenshot](race-man6-tune.png) matches the **Baiern Devils RaceMan6 6 speed race manual transmission** in the Java source (`2.7 / 2.2 / 1.8 / 1.5 / 1.2 / 1.0`, final drive `2.73`). Its [data](race-man6.json) are kept separately because this is not the stock CoupeSport gearbox. The UI displays `1.799` for third gear where the source says `1.8`; the `0.001` difference remains unexplained.

Reference figures: 1482 kg, rear-wheel drive, 2714 cm³ (six cylinders, 80 × 90 mm bore and stroke), 1000 rpm idle, 7000 rpm redline, 205 N·m at 4500 rpm, and 194 hp at 6250 rpm. The five gear ratios and final drive are shown in the game. The stock-car targets are **0–100 km/h in 6.109 s**, **quarter mile in 14.542 s**, and **one mile in 39.763 s**. The game labels elapsed times and finish speeds as separate best results, possibly from different runs; matching one speed should not come at the expense of the corresponding elapsed time.

`npm run report:stock-benchmark` assembles the stock `Baiern.rpk:0x06` from local game files and displays the game's figures alongside recognized Java/CFG parameters and the calculated torque curve. `npm run measure:stock-drive` runs a straight-line acceleration on level ground: it starts in neutral, selects first gear, and measures shift points, 0–100 km/h, the quarter mile, and the mile. `npm run verify:stock-drive` also checks acceleration and gear order. Reading the installed files makes it possible to compare other releases and mods.

With a general calibration applied to all cars, the current straight-line run reaches **100 km/h in about 6.10 s**, covers the quarter mile in **14.60 s**, and the mile in **39.78 s**. The gearbox shifts 1→2→3→4→5 in order. CFG physical bodies total **1489.6 kg**, close to the game's 1482 kg; a former per-part minimum-mass rule inflated this to 1673 kg. Traction transfer still includes a general empirical speed-dependent correction. This is a driving calibration, not a recovered native algorithm, and needs validation on other stock cars and mods.

There are discrepancies that cannot be eliminated by a single physics coefficient:

- The Java source gives stock ratios of `3.58 / 2.49 / 1.66 / 1.24 / 1.00` and a final drive of `3.03`; the screen shows `3.579 / 2.490 / 1.659 / 1.240 / 1.000` and `3.029`. The consistent `0.001` display difference needs investigation.
- The displayed `97.3 hp/L` does not follow from `194 hp / 2.714 L` (about `71.5 hp/L`). Likewise, the displayed `74.132 kg/N·m` differs from `1482 / 205` (about `7.23 kg/N·m`). These derived figures are retained as UI observations, not tuning targets.
- `194 hp` at `6250 rpm` requires roughly `221 N·m` at that engine speed, exceeding the stated peak torque of `205 N·m`. The graph and labels may use different definitions of power or torque, or the game may display one value incorrectly. Until this is checked, the physics curve cannot be required to match both peaks exactly.

A fully comparable automatic run also requires the original game's tire size and grip, drag coefficients, engine condition, drivetrain losses, shift behavior, surface, and start/finish rules. Those cannot be recovered from these three screens alone.
