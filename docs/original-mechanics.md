# Штатные узлы Baiern: сборка и влияние повреждений

Проверено на локальной модифицированной Steam-установке SLRR. Режим **«Машина и препятствие»** собирает Baiern CoupeSport (`cars/racers/Baiern.rpk`, ресурс `0x06`) из **72 объектов** без ошибок совместимости: прежние 33 кузовных, колёсных и интерьерных объекта плюс 39 объектов, выбранных через `addStockParts` (включая 20 узлов двигателя). Для других машин такой набор пока не проверен. Ресурсы игры читаются с диска локальной установки и не добавляются в Git.

## Откуда взят состав

`cars/racers/Baiern_data/scripts/src/Baiern_CoupeSport.java` наследует `Baiern_models.java`. Его `addStockParts` задаёт стандартный двигатель и четыре стойки, четыре пружины, четыре амортизатора, четыре тормоза и два стабилизатора. За исходный выбор взят `desc.power = 1` (ветка штатной комплектации) и `MODEL_COUPESPORT`. Исходные Java-ветки выбираются ограниченным читателем выражений; `RID` разрешается через зависимости RPK, крепления — по `slot`, `attach`, `compatible`, затем рекурсивно читаются `addStockParts` деталей двигателя. Он не исполняет Java-конструкторы, native-функции, случайные ветви и общий игровой lifecycle. Неизвестные условные выражения не исполняются; неустановленные детали выводятся предупреждением.

Выбранный RPK ресурс передних амортизаторов (`parts/running_gear` `0xFD`) указывает на `shock_absorber_Ishima_WRY_front`, несмотря на комментарий Baiern в скрипте. Берётся фактический ресурс и его `damping = 3300`, а не имя из комментария. Задние дают `3000`. Штатные пружины CoupeSport задают `kgfPmm2NPm(7.3)` = **71 613 Н/м** спереди и **73 575 Н/м** сзади; `restlength = Inch2Meter(8.5)` = **0.2159 м**. Для этих простых выражений используется арифметический парсер с белым списком преобразований единиц; исходный Java не выполняется.

Нумерация слотов оригинального CFG связывает узлы с углами: `121–124` стойки, `301–304` амортизаторы, `311–314` пружины, `111–114` тормоза. Для видимых креплений `slottype 201–204` и `301–304` используются соответствующий `wheel` frame и локальное смещение самого CFG-слота, без поправок под Baiern. Ранее мы дополнительно прибавляли `setArm` к точке установки пружины и получали пружины внутри машины; это внутренняя физическая точка рычага, а не координата видимого крепления. `setHub/setArm` по-прежнему считываются из Java-профиля, но их точная native-семантика и шарнирные связи не восстановлены. Движение колёс пока рассчитывают четыре лучевые опоры.

## Состояние и движение

У каждой установленной детали собственное состояние `condition` от 100% до 0%. Нагрузку при ударе получают близкие к контакту узлы; двигатель частично прикрыт кузовом в модели передачи удара. Нулевое состояние стойки оставляет её на шасси, но освобождает колесо. Нулевое состояние блока освобождает двигатель **целиком**: все вложенные узлы остаются в его дереве креплений. Нулевое состояние внутреннего узла останавливает его функцию, не разбивая двигатель на отдельные физические тела.

| Узел | Действие в текущей модели |
|---|---|
| Стойка и пружина | Жёсткость опоры масштабируется их состоянием; при 0% пружины опора перестаёт держать колесо. При 0% стойки колесо отделяется и падает, стойка остаётся на машине. Перекос колеса появляется при состоянии **ниже 10%** стойки/опоры. |
| Амортизатор | Демпфирование из выбранного Java-класса умножается на состояние. |
| Стабилизатор | Исходные `force/damping` сопротивляются разному ходу левого и правого колеса оси; повреждение уменьшает этот момент. |
| Тормоз | Тормозная сила данного колеса умножается на состояние тормоза и стойки. |
| Блок, коленвал, ГБЦ, трансмиссия, сцепление, топливная рампа | Доступная тяга ограничена самым слабым обязательным узлом. 0% любого из них обнуляет тягу; при 0% блока вся силовая установка отделяется как единое тело. |

Из блока и коленвала считаны 6 цилиндров, диаметр 80 мм и ход 90 мм (**2.714 л**); из коробки — пять передач, первая `3.58`, главная пара `3.03`, задний привод `DT_RWD`. Для демонстрации силы использована оценка 9 бар BMEP, КПД передачи 0.82 и простое переключение по оборотам. Это **новая приближённая модель**, не оригинальная кривая момента, сцепления, сгорания или алгоритм АКПП. Шины, геометрия кинематики и независимые неподрессоренные массы пока не доведены до оригинальной физики. Стабилизатор действует простой парой противоположных сил, а не исходными шарнирами.

Жёсткие меши механических частей рендерятся по оригинальным SCX и креплениям. Java-классы тормозов задают четыре `renderID_FL/FR/RL/RR`: это один тип детали с разными мешами по углам. При установке выбирается соответствующий RID, иначе правый тормоз использовал бы левый меш и выступал на внешней стороне диска. Стойка, пружина, амортизатор и тормоз каждого угла перемещаются и поворачиваются вместе с несущим узлом колеса при ходе подвески; вращение шины вокруг оси им не передаётся. Это пока движение группы как единого целого, без изменения длины пружины и кинематики каждого шарнира. Стабилизатор остаётся закреплённым на кузове. Для отделённого двигателя масса суммируется по вложенным деталям, а общий collider охватывает их исходные меши; решается **одно** твёрдое тело. Отделённое колесо получает отдельное твёрдое тело и взаимодействует с полом, препятствием и кузовом. Пока узлы установлены, их собственные визуальные bounding box не создают лишних контактов. В сцене флажок **«Внутренние узлы»** скрывает кузов; кнопки **«Отрыв двигателя»** и **«Обрыв левой стойки»** выставляют 0% соответствующему узлу для воспроизводимого осмотра. `R`/«Сброс» восстанавливает сборку и состояние.

## Воспроизведение

`npm test` проверяет арифметику и выбор ветви без исполнения исходника, чтение четырёх render ID тормоза, изменение опоры, демпфирования, тормозов и тяги, движение видимых деталей с колесом при неподвижном стабилизаторе, а также цельный отрыв двигателя и падение колеса при оставшейся стойке. `npm run verify:components` читает настоящую локальную установку и проверяет 72 установленные детали, расположение механических узлов у всех четырёх колёс, четыре соответствующих меша тормозов, 20 узлов двигателя, реальные значения пружин/амортизаторов и реакцию на повреждение. `npm run build` проверяет строгий TypeScript и сборку браузера.
