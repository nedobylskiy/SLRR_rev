# UV контейнеров Test Track

`objects.rpk:0x522` связывает `objects/meshes/kontener/kontener.scx` с `maps/textures.rpk:0x11f` (`maps/textures/kontener.dds`). Материал SCX содержит одну карту `DiffuseMixSecond`, индекс 0, UV-канал 0, масштаб 1×1 и смещение 0. У render-ресурса нет дополнительного преобразования UV. Один только разворот V не может совместить рисунок на всех гранях.

В SCX 12 треугольников кубоида и шесть отдельных UV-прямоугольников. Их границы по V расположены около 0, 1/3, 2/3 и 1. По нормалям граней: короткие торцы X± используют правые области второго и третьего рядов, длинные стороны Z± — левые области первого и второго, верх и низ — оставшиеся области первого и третьего. Это осмысленная развёртка под атлас 2 колонки × 3 ряда.

В текущей Steam-установке `kontener.dds` имеет размер 512×512 и другой атлас: двери в верхней левой четверти, боковины — в верхней правой и нижней половине. Границы его рисунка не совпадают с UV-границами SCX, поэтому на гранях видны части соседних областей. `kontenertext1.dds` имеет размер 256×256 и атлас 2×3, совпадающий с развёрткой, но его рисунок ржавый, а не золотистый с референсного снимка.

Сравнение с переданным архивом исследователя Elias (`local/SLRR-REVERSE-WIP.zip`) уточняет происхождение расхождения:

| Ресурс | Архив Elias | Текущая Steam-установка |
|---|---|---|
| `kontener.scx` | SHA-256 `15a81b2c7164…` | тот же файл |
| `kontener.dds` | SHA-256 `2bb7a6c5d0cd…`, 256×256, ржавый атлас 2×3 | SHA-256 `02a6d10f03ca…`, 512×512, золотистый атлас 2×2 |
| `kontenertext1.dds` | SHA-256 `2bb7a6c5d0cd…` | тот же ржавый атлас 2×3 |

Рендер-ссылка RPK на `kontener.dds` осталась той же. Следовательно, здесь есть несовпадение конкретной версии текстуры с неизменённой развёрткой модели. Из наличных SCX/RPK нельзя вывести универсальную перестановку областей нового атласа: текстура не хранит соответствие граней. Случайная глобальная перестановка UV ухудшила бы другие модели и моды.

По выбранному для тестовой сцены варианту рендер берёт сохранившийся в той же установке старый атлас `kontenertext1.dds`. Координаты UV модели не меняются. Подмена срабатывает лишь для проверенной штатной пары: путь, отпечаток геометрии SCX и SHA-256 обоих DDS должны совпасть. При других ресурсах, включая моды, действует обычная ссылка из RPK. Это совместимость данных конкретной версии, а не правило исходного движка. Цвет контейнеров пока будет ржавым и не совпадёт с золотистым референсом; положение рисунка на гранях нужно проверить визуально в тестовой сцене.
