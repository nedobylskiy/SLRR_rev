# Экранное меню и OSD

Первый экран OSD использует `sl/Scripts/game/src/MainMenu.java` из подключённой установки SLRR. Ограниченный интерпретатор выполняет настоящие тела `MainMenu.enter()`, `Gates.buildSlidingMenu()`, `Gates.osdCommand()` для навигации и `MainMenu.exit()`. Состояние игры передаётся в узкий Java-host; сейчас это начальное состояние без карьеры и сохранённой машины. Поэтому список, условия появления пунктов, команды, ссылки на RPK-ресурсы, размеры и первоначальный выбор формируются исходным Java-кодом. Стрелки вызывают `osdCommand()`, который обращается к `SlidingMenu.execute()`; результат отражается на экране.

`OsdLayer` размещает элементы в экранных координатах исходного OSD: центр `(0, 0)`, края `(-1, -1)` и `(1, 1)`, ось Y направлена вниз. Слой имеет фиксированное отношение сторон 16:9 и не зависит от камеры Three.js. Он предоставляет прямоугольники с изображениями, текст, кнопки, группы с управлением видимостью и освобождение загруженных ресурсов. Это основа для следующих Java-управляемых экранов.

Главное меню появляется при подключении установки с Java-исходником и `frontend.rpk`, его можно снова открыть кнопкой «Главное меню». Карусель показывает семь соседних пунктов с оригинальными иконками; выбор работает стрелками или кнопками на экране, Enter активирует пункт, Esc возвращает каталог ресурсов. `FREERIDE` уже открывает поездку по тестовому треку. Вызовы `runAnimation()` и `teleport()` из `Gates.showPrimaryVisuals()` задают появление полосы, карусели и логотипов. При закрытии выполняется `Gates.cleanup()`, включая `reverseAnimation()`; общие операции движения реализованы в `OsdMotionController`. Пока движение по исходным шагам приближено браузерной анимацией с длительностью 16 мс на шаг, а не кадровым циклом оригинального движка. Фон берётся из предусмотренного скриптом `data/Fmv/background_motion_HD.avi`: локальный сервер конвертирует Cinepak в WebM для браузера и сохраняет результат в памяти. Если ролик отсутствует или не воспроизводится, отображается исходный `bck.png` из `frontend.rpk`. Файлы игры в репозиторий не копируются.

Рендеринг рамки, логотипов и фонового ролика пока является адаптером для данной версии: метод `Gates.show()` ещё не исполняется целиком, а его вызов через host передаёт управление `buildSlidingMenu()`. Команды запуска карьеры, загрузки и других экранов пока не выполняют свои Java-ветки; `FREERIDE` подключён к текущей поездке отдельно. Поэтому совместимость с произвольными версиями и модами пока не гарантирована. Интерпретатор не использует JavaScript `eval` и отвергает неподдерживаемые операции.
