# Экранное меню и OSD

Первый экран OSD восстановлен по `sl/Scripts/game/src/MainMenu.java` из подключённой установки SLRR. Картинки и значки берутся по идентификаторам из её `frontend.rpk`. Начальный выбор — `NEW CAREER`, как в `Gates.buildSlidingMenu()`; порядок пунктов и команды сохранены.

`OsdLayer` размещает элементы в экранных координатах исходного OSD: центр `(0, 0)`, края `(-1, -1)` и `(1, 1)`, ось Y направлена вниз. Слой имеет фиксированное отношение сторон 16:9 и не зависит от камеры Three.js. Он предоставляет прямоугольники с изображениями, текст, кнопки, группы с управлением видимостью и освобождение загруженных ресурсов. Это основа для следующих Java-управляемых экранов.

Главное меню появляется при подключении установки с `frontend.rpk`, его можно снова открыть кнопкой «Главное меню». Выбор работает стрелками или кнопками на экране, Enter активирует пункт, Esc возвращает каталог ресурсов. `FREERIDE` уже открывает поездку по тестовому треку. Прочие пункты сохраняют исходные команды, но ждут переноса соответствующей игровой логики. Фоновое видео из `MainMenu.java` пока заменяет предусмотренный там же статичный фон.
