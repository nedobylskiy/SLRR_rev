# Экранное меню и OSD

Первый экран OSD использует `sl/Scripts/game/src/MainMenu.java` из подключённой установки SLRR. Ограниченный интерпретатор выполняет тела `MainMenu.enter()`, конструктора и `Gates.show()`, `Gates.buildSlidingMenu()`, `Gates.osdCommand()`, цикл `Gates.run()` по одному тику, `ColorBank` и `MainMenu.exit()`. Состояние игры передаётся в узкий Java-host; сейчас это начальное состояние без карьеры и сохранённой машины. Список, условия появления пунктов, команды, ссылки на RPK-ресурсы, размеры, первоначальный выбор и пульсация цвета надписи формируются исходным Java-кодом. Стрелки вызывают `osdCommand()`, который обращается к встроенному `SlidingMenu.execute()`; адаптер этой функции ограничивает выбор крайними пунктами.

`OsdLayer` размещает элементы в экранных координатах исходного OSD: центр `(0, 0)`, края `(-1, -1)` и `(1, 1)`, ось Y направлена вниз. Слой имеет фиксированное отношение сторон 16:9 и не зависит от камеры Three.js. Он предоставляет прямоугольники с изображениями, текст, кнопки, группы с управлением видимостью и освобождение загруженных ресурсов. Это основа для следующих Java-управляемых экранов.

Главное меню появляется при подключении установки с Java-исходником и `frontend.rpk`, его можно снова открыть кнопкой «Главное меню». Слайдер конечен; выбор работает стрелками или кнопками на экране, Enter активирует пункт, Esc возвращает каталог ресурсов. `FREERIDE` уже открывает поездку по тестовому треку. Вызовы `runAnimation()` и `teleport()` из `Gates.showPrimaryVisuals()` задают появление полосы, слайдера и логотипов. При закрытии выполняется `Gates.cleanup()`, включая `reverseAnimation()`; общие операции движения реализованы в `OsdMotionController`. Движение по исходным шагам приближено браузерной анимацией с длительностью 16 мс на шаг. Фон берётся из предусмотренного скриптом `data/Fmv/background_motion_HD.avi`: локальный сервер конвертирует Cinepak в WebM для браузера и сохраняет результат в памяти. Если ролик отсутствует или не воспроизводится, отображается исходный `bck.png` из `frontend.rpk`. Файлы игры в репозиторий не копируются.

Вызовы соседних систем из `Gates.show()` (звук, видео, загрузочный экран, курсор, другие игровые скрипты) пока реализованы узкими заглушками. Рендеринг рамки, логотипов, стрелок и фонового ролика остаётся адаптером этой версии; первая заставка пропускается, а `Gates.showPrimaryVisuals()` вызывается после входа. Команды запуска карьеры, загрузки и других экранов пока не выполняют свои Java-ветки; `FREERIDE` подключён к текущей поездке отдельно. Для проверки совместимости с более ранней версией нужен её `MainMenu.java` и ресурсы: иной исходник может потребовать расширения Java-интерпретатора или встроенного OSD API. Интерпретатор не использует JavaScript `eval` и отвергает неподдерживаемые операции.
